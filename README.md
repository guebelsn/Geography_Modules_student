# Geography_Modules_student

This repo includes data science modules in a jupyter notebook format to be integrated in Geography courses as part of the curriculum at Santa Barbara City College (SBCC). The notebooks are meant to be student assignments for lower-division Geography courses. Students do not have to have programming experience. This repo provides a way to expose students to coding while covering the core topics in the Geography courses.
The Jupyter Notebooks follow the same format used in SBCC’s Data Science course, CS/MATH 118 (Data Science for All), which is modeled after UC Berkeley’s Data 8 course.
